# Print Team Name — 順位表 → A4印刷用一覧

順位表のスクリーンショットを読み込むと、エンブレム・チーム名・順位を取り出してA4縦1ページの一覧表を作る静的サイトです。ビルド不要で、`main` に push すると GitHub Pages に自動デプロイされます。

## 仕組み

| 項目 | 処理 |
| --- | --- |
| エンブレム | ブラウザ内で Canvas から切り出し・背景透過。外部送信なし |
| チーム名 | ページから直接取り込み／ブラウザ内OCR（無料・自動）／貼り付け／Claude の vision |
| 出力 | 画像をbase64で埋め込んだ単一HTML（A4縦・印刷用） |

順位が1件も入っていない一覧では、順位の列ごと省いて出力します。読み込んだ画像は保存されません。エンブレムの検出は、背景色を推定して行の帯を求め、各帯の中で「行の高さいっぱいのほぼ正方形の塊」だけを拾います。順位の数字・増減の矢印・チーム名の文字列は形状で除外されます。1列の一覧でも左右2列の順位表でも読み順どおりに並びます。

## チーム名の入れ方

4通りあります。順位表ページのURLがあるならZが最も正確で手数も少ないです。スクショしか無いときは既定のA、うまく読めなければB、費用を許容できるならCです。

### Z. 順位表ページのURLから取り込む（無料・最も正確）

順位表ページのURLを貼って「読み込む」を押すだけです。チーム名はページの文字列そのものなので**誤読ゼロ**、エンブレムは元画像を使います。

ブラウザは他サイトのHTMLを直接読めない（CORS）ため、取得サービス **`r.jina.ai`** を1つ経由します。**貼ったURLはそのサービスに送られます。** 公開ページの取得のみですが、外部に送りたくない場合は下のブックマークレットを使ってください。

返ってくるのはMarkdown化されたページで、表の行にチームへのリンク（`/team/<ID>`）が残ります。そこから名前とIDを取り、IDでエンブレムのURLを組み立てます。同じページの別の表（日程や得点者）に同じチームが出てくるので、IDで重複を除きます。

エンブレムはCORSの都合でURL参照になります。**A4のHTMLは自己完結せず、印刷時にネット接続が必要です。**

#### ブックマークレット（現在は画面に導線がありません）

`collect.js` は残っていますが、Figmaでのデザイン更新にともない、ブックマークレットの登録リンクと「まとめて貼り付け」欄を画面から外しました。使う場合は `collect.js` を1行化してブックマークに登録し、受け取ったJSONを取り込む導線を戻す必要があります。

エンブレムは `<img>` とは限らず、CSSの背景画像で描かれていることもあるので両方拾います。表（`<tr>`）の中にある候補があればそちらを優先します。サイトのナビゲーションにもアイコンが並んでいることが多く、数だけで選ぶとそちらを掴んでしまうためです。仕組みは `collect.js` に読める形で置いてあり、ページに埋め込んだ1行版はそこから生成しています。

### 動作を確認したサイト

スポーツナビの順位表（例: `https://soccer.yahoo.co.jp/ws/category/por/standings`）で、URL経由・ブックマークレットの両方で18クラブすべてを取得できました。チーム名は完全一致、エンブレムは120pxのPNGで、画面表示（28px）より高解像度です。

エンブレムのURL組み立てはスポーツナビの形式に対応しています。リーグの区分（海外サッカーは `ws`、Jリーグは `jleague`）はチームへのリンクから取り出すので、リーグを問わず動きます。

```
https://soccer.yahoo.co.jp/jleague/team/199
  → https://s.yimg.jp/images/sports/soccer/jleague/logo/team/120/199.png
```

動作確認: 海外サッカー・ポルトガル（18クラブ）、Jリーグ・J2（20クラブ）。いずれもチーム名は完全一致、エンブレムは全件表示できました。スポーツナビ以外のサイトではチーム名だけが入り、エンブレムは空になります（その件数を知らせます）。

### A. ブラウザ内OCR（無料・自動・既定）

画像を読み込むと Tesseract.js が自動で走り、チーム名が入ります。キーも通信先も不要で、画像はブラウザの外に出ません。日本語モデルは初回だけ CDN からダウンロードされ、以降はブラウザにキャッシュされます。

検出済みのエンブレムの座標を使い、行ごとに「エンブレムの右から、同じ行の次のエンブレム（無ければ画像の右端）まで」を切り出して1行として読ませます。そのため順位の数字や増減の矢印は範囲に入りません。

**精度は完璧ではありません。** 手元の2枚（ベルギー・ポルトガル、各18クラブ）では、エンブレムは36件すべて正しく切り出せましたが、名前の完全一致は18件中14件と15件でした。誤りは「ゲンク→グンク」「ポルト→ボルト」のような濁点・小さいカナの取り違えです。一覧でその場で直せますが、数が多いときはBが早いです。

### B. まとめて貼り付け（現在は画面に導線がありません）

macOS は画像の中の文字をそのまま選択できます。スクショを「プレビュー」かクイックルック（スペースキー）で開き、チーム名の列をドラッグで選択して⌘C、ページの「チーム名をまとめて貼り付け」欄に⌘Vして「名前を流し込む」を押すと、上から順に各行へ入ります。OSの認識精度はTesseractより高いので、Aで誤読が多いときはこちらが確実です。

貼り付けた文字列は次のように整えられます。

- 空行、順位の数字だけの行、増減の矢印だけの行は読み飛ばす
- 「1 チーム名」のように行頭に付いた順位は落とす
- 行数がエンブレムより多ければ、エンブレムなしの行として足す

APIも通信も発生しません。認識はOSに任せます。

### C. Claude に読ませる（現在は画面に導線がありません・従量課金）

Anthropic の API を呼ぶのでキーが要ります。画像1枚につき vision の呼び出しが1回発生します。設定方法は2つあります。

#### C-1. 利用者が自分のキーを入れる（追加サーバー不要）

ページ上の「チーム名の自動読み取り設定」にキーを貼って保存すると、そのブラウザの `localStorage` にだけ保存され、`x-api-key` を付けて API を直接呼びます。自分だけが使うツールならこれで十分です。

**キーをリポジトリに書かないでください。** GitHub Pages は静的配信なので、コードに書いたキーは閲覧者全員に見えます。Actions の Secrets も同様で、静的ファイルに埋め込んだ時点で公開されます。

#### C-2. プロキシを立てる（サイトを他人にも使わせる場合）

Cloudflare Workers や Vercel Functions にキーを持たせ、そこ経由で呼びます。`app.js` 冒頭の `PROXY_ENDPOINT` にそのURLを入れると、キー入力欄は消えてプロキシ経由になります。

Cloudflare Workers の最小例:

```js
export default {
  async fetch(req, env) {
    const cors = {
      "Access-Control-Allow-Origin": "https://ske80225-lab.github.io",
      "Access-Control-Allow-Headers": "Content-Type",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
    };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    const r = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-api-key": env.ANTHROPIC_API_KEY,
        "anthropic-version": "2023-06-01",
      },
      body: await req.text(),
    });
    return new Response(await r.text(), {
      status: r.status,
      headers: { ...cors, "Content-Type": "application/json" },
    });
  },
};
```

キーは `wrangler secret put ANTHROPIC_API_KEY` で登録します。`Access-Control-Allow-Origin` は自分のPagesのオリジンに絞ってください。誰でも叩ける状態だと課金がそのまま乗ります。

キーもプロキシも設定されていれば C が使われ、未設定なら自動的に A が使われます。

## 使い方

1. スクショをドロップ / クリックで選択 / ⌘V で貼り付け
2. チーム名は自動で入る。誤読が多ければ「まとめて貼り付け」を使う
3. 一覧を確認し、誤りがあればその場で修正（行の追加・削除も可）
4. 表題と列数を決めて「A4用HTMLをダウンロード」
5. ブラウザで開いて印刷（用紙A4・背景のグラフィックをオン）でPDF化
